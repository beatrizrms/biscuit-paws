# Biscuit Paws

Simulador 2D de café de gatos, no estilo Stardew Valley, para a Steam.
Phaser 3 + TypeScript + Vite. Resolução interna 640 x 360, escala inteira, grade de 32 px.

Estado atual: **Marco 0.5, a chegada.** Você compra a velha padaria vazia (sem balcão, paredes e piso gastos), começa com pouco dinheiro, compra e posiciona móveis, chama o Tião para as obras e segue as primeiras metas da história. O jogo salva sozinho.

## Antes de rodar: a arte

A arte é licenciada e **não vai para o Git** (veja `docs/ART_AND_LICENSE.md`). Os pacotes ficam intactos em `assets/_originais_pacotes/<pacote>/`; o jogo carrega só `public/assets/`, organizado por função (`env/`, `interiors/`, `objects/`, `characters/`, `ui/`, `icons/`), com nomes no padrão de `docs/ASSET_REORGANIZATION.md`. Copie os arquivos para:

| Arquivo | Destino |
| --- | --- |
| `cat-cafe-tileset.png` (pacote Cat Cafe 32x32, pasta `tiles/`) | `public/assets/interiors/cafe/tile_cafe.png` |
| pacotes `ui_menus`, `inauguracao` e `audio` (zips) | `assets/_originais_pacotes/<pacote>/`, depois rode `npm run ui-audio` |
| pacote `rua_estacoes_tilesets` | `assets/_originais_pacotes/rua_estacoes_tilesets/`, depois rode `npm run seasons` |
| pacote `quintal_secreto` (zip) | `assets/_originais_pacotes/quintal_secreto/`, depois rode `npm run backyard` |

## Comandos

```bash
npm install
npm run dev         # abre o jogo em http://localhost:5173 (refaz data/tiles.json sozinho quando os dados de tiles mudam)
npm run art         # gera os tiles "velhos" a partir da folha do pacote (roda sozinho no dev e no build)
npm run art:placeholders  # arte provisória desenhada por código (caixa de areia, cocô); roda sozinho no dev
npm run check       # tipos + validação de todo o conteúdo (mapas, itens, história, falas)
npm run vet         # importa a clínica (Fernanda e interior) de assets/_originais_pacotes para public/assets
npm run mannequin   # monta as peças da personagem (manequim, roupas e cabelos do PixelLab, 64 px) em public/assets/characters/player_mannequin
npm run npcs        # monta as folhas dos NPCs na arte nova (Gabi, Corretora, Dona Neusa, Jacque, Entregadora, Fernanda só com a caminhada, a atendente do mercado só de costas, o Joca e os 10 clientes com caminhada e sentado) em public/assets/characters/npcs/v64
npm run gatos       # monta as folhas dos gatos na arte nova (64 px, layout do Cosy Cats + comer e estranhar) em public/assets/characters/cats: o ruivo (âncora) e as pelagens de assets/_pixellab/gatos/base_<pelagem>
npm run pixellab    # junta a arte aprovada do PixelLab (assets/_pixellab) em folhas de 64 px em public/assets (café, cômodos, mercado, clínica, rua, quintal, ícones e mini games)
npm run minigames   # importa a arte dos mini games de assets/_originais_pacotes/minigames para public/assets/minigames
npm test            # testes da lógica pura (Vitest)
npm run test:e2e    # teste de fumaça no navegador (Playwright)
npm run build       # build de produção em dist/
```

Na primeira vez que rodar o teste de fumaça, instale o navegador do Playwright: `npx playwright install chromium`.
Os prints do teste ficam em `test-results/`.

Controles:
- **E perto da sujeira, ou clique nela** (de perto, com a vassoura ativa na barra): limpar. Manchas e rachaduras só saem com o reparo interno do Tião.
- **1 a 8 / roda do mouse:** escolher o item ativo na barra (embaixo da tela). **I:** mochila no centro da tela: a barra em cima e a grade embaixo. Selecione um item para ver o que ele faz; para pôr na barra, arraste até um espaço, ou selecione e aperte 1 a 8 (arrastar da barra para a grade tira da barra). Embaixo, a **despensa** (só ver, longe do armário): os ingredientes guardados e as doses de cada um. **Caixa pet** (Market, aba Pet, grupo Organização): um baú de 8 espaços para as coisas dos gatos (ração, areia, petiscos, brinquedos e cuidados; cada espaço guarda um tipo, em qualquer quantidade). Tudo chega na mochila primeiro; E na caixa (de mãos livres) abre a mochila com a caixa embaixo: selecione um item e "guardar na caixa" (ou arraste até a caixa); na caixa, "pegar" (ou arraste de volta). **Empilhar** (como no Stardew Valley): cada storage tem o seu botão, que leva da mochila só o que já está nele, para repor (na caixa pet e na despensa). Recolher a caixa devolve o que estava dentro para a mochila. **Despensa:** ingrediente comprado (mercado ou Market) vai para a mochila; no café, E no **armário da cozinha** (ao lado da pia) abre a despensa (24 espaços; a barra de baixo some enquanto a mochila está aberta) com o botão **guardar da mochila** (tudo) e, num ingrediente selecionado, **guardar na despensa** (só ele; ou arraste até a despensa). Só o que está na despensa vale nas receitas; enquanto houver compra na mochila, o balão lembra "Guardar as compras na despensa". **Cortinas:** E (ou clique) na janela do café abre e fecha a cortina; a luz do sol só entra no chão pela janela aberta. Na primeira vez que abre, ela comenta a vista (uma vez no jogo), e a dica "E" da cortina aparece só até o primeiro uso (`hintTimesBy` em `data/world.json`). Antes da limpeza pesada do quintal (o Tião), a janela aberta mostra galhos tapando a vista (`ph_window_branches`, arte `02_cafe_2/janela_aberta_galhos_128.png`); depois, a vista limpa (`ph_window_open`, `02_cafe_2/janela_aberta_128.png`). Se o jardim já estiver aberto quando ela abrir a cortina pela primeira vez, ela não comenta os galhos. À noite (18:00 às 07:00), a primeira vez tem outra fala, sem o sol; e o céu do vidro das janelas abertas escurece com a hora de fora (só os pixels de céu: moldura, cortina e galhos ficam com a luz de dentro). **Brincar:** com pelo menos 1 brinquedo (móveis com a tag `cat:toy`) para cada 3 gatos, cada gato pede para brincar (balão da varinha) a cada 4 dias, +1 dia por brinquedo a mais e por outro gato, até 8; ignorar só deixa o balão. Com menos brinquedos, ele pede todo dia e fica triste se ninguém brincar. Brincar com a varinha zera a contagem (números em `data/health.json: care.play`). Gato com balão de cuidado (pegadas de lama = sujo, coração = triste, remédio) também vira lembrete no subconsciente, dizendo o que fazer (escovar, brincar, dar o remédio) ou onde comprar a escova/varinha. **Corações** (afeto, `data/relationships.json`): 100 pontos = 1 coração, até 10. Comer da tigela que ela encheu (ou do pote automático) dá +30 por dia; petisco na mão, +40; escova, varinha e remédio, +10 (ok) ou +20 (perfeito). Descuido: com a saúde, a alegria ou a higiene em zero por 2 dias seguidos, o gato perde 1 coração (e aparece um aviso). Com a **ração** ativa, E na tigela enche (uma porção serve todos os gatos do dia; com a **ração premium**, os gatos ganham 25% mais saúde no fim do dia: `healthMultiplier` em `data/items.json`); com a **areia** ativa, E na caixa de areia troca a areia (todo dia; sem areia limpa, a higiene dos gatos cai; com 2 dias seguidos sem areia limpa, cada gato faz cocô no chão num lugar sorteado, até 3, e o subconsciente lembra de varrer e trocar a areia: `data/health.json: care.litterPoop`); com o **petisco** ativo, E perto do gato dá o petisco. Upgrades no Market (só aparecem **depois da inauguração**, também na Assistência técnica): **lava-louças**, **pote de ração** e **caixa de areia automáticos** (colocar em cima da tigela/caixa comum, que vira o automático) guardam até 10 dias e servem sozinhos (abasteça com a ração/areia na barra; os sacos de 10 kg rendem 10 dias). **Sacos** (ração 5 porções, areia 4 trocas, os de 10 kg): vão para a mochila e a barra; só quando o saco está **selecionado na barra** ele fica nas mãos e ela anda mais devagar. No café, com ele selecionado, E guarda e ele vira as porções/trocas. Com a tigela e a caixa de areia lado a lado, o E vai na que está na frente dela. Olhando para uma interação do mapa (a janela, uma plaquinha) até o alcance dela, o E vai nela, mesmo com a despensa, a pia ou um equipamento ao lado (só um equipamento bem na frente dela ganha). A poeira que volta de manhã cai em lugares livres sorteados do chão, diferentes a cada dia.
- **Cuidados dos gatos:** cada gato tem alegria e higiene, que caem um pouco a cada dia. Quando algo está baixo, um balãozinho aparece em cima dele no café (remédio, sujo ou triste). Os mini games de cuidado (varinha, escova, remédio escondido) sobem os dois. **Varinha de penas** (18 moedas, prateleira pet do mercado): com ela ativa na barra, E perto de um gato do café abre **Brincar com a varinha**: o mouse é a ponta; mude de rumo e de ritmo para empolgar; reta constante ou rápido demais, ele enjoa; pare perto dele e ele se agacha e dá o bote (balance de leve durante o agachar: bônus); depois do bote, a presa precisa fugir de novo antes do próximo: parada perto dele sem bote, ele enjoa ("Presa parada, que tédio..."). A dificuldade vem do jeito do gato. **Escova de pelo** (15 moedas, mesma prateleira): E no gato abre **Banho e escovação**: o gato grande, de lado, com nós de pelo; segure e arraste a escova sobre cada nó até sumir (só o vaivém conta, clicar não). Barriga, cauda e patas são sensíveis e gastam a paciência dele; costas e bochechas ele adora e a paciência volta um pouco. Paciência zerada, ele foge. Sobe a higiene (e um pouco a alegria). **Remédio:** com o remédio da receita na mão, E no gato doente abre **Remédio escondido**: primeiro cubra o comprimido com a pasta (segure e arraste, até 100%) e aperte E (Pronto); depois ofereça (E) quando ele estiver de costas, distraído. De frente com "!", ele vê e desconfia; o "?" tremendo avisa que ele vai virar. Oferecer com o comprimido aparecendo também dá desconfiança; cheia, ele recusa e foge (dá para tentar de novo). Deu certo, a dose do dia vai. Gato desconfiado (tímido, rabugento) se distrai por menos tempo.
- **Clínica e castração** (`data/clinic.json`, falas em `data/vet_text.json`, decisão 173): depois que a clínica abre, todo gato abrigado espera isolado (no **cercadinho de recuperação**, Market aba Pet, 3x2, até 4 gatos; sem cercadinho, na caixinha de transporte num canto do salão) até a **consulta de entrada**: pegue o gato (E no cercadinho), leve à clínica (fora do café ele vai na caixinha) e E no balcão. A consulta (paga; a partir da 5ª, a Fernanda dá 20% de desconto de amiga; sem dinheiro e sem dívida, fica no fiado e a dívida é paga junto na próxima castração) faz os testes de FIV e FeLV (negativos por enquanto), diz se ele já é castrado (antes disso a ficha mostra "não sei ainda"; orelha marcada = castrado), o sexo, a idade e o peso, e trata a doença se houver. Depois, duas opções: **Castrar** (tudo incluso: ele dorme na clínica e de manhã a Fernanda leva ao cercadinho, com o remédio de 3 dias e latinhas; quando ela entra no café, a Fernanda está ao lado do gato, conta como foi e sai pela porta. Sem vaga no cercadinho, ele volta na **caixinha de transporte**: E pega a caixinha, que continua caixinha no colo; longe do cercadinho, o E põe a caixinha no chão na frente dela; perto de um cercadinho com vaga, o gato sai dela e vai para lá. Comprar o cercadinho não tira ninguém da caixinha sozinho) ou **Hoje não! Volto outro dia** (junta-se aos outros e aí vem a confiança; para castrar depois, é só trazer de novo ao balcão; já castrado ou novo demais, o botão é **Levar para o café**). Novo demais, magro, fraco ou doente: não opera ainda (a ficha diz "aguardando idade" com o dia). Já castrado: a Fernanda avisa e não opera. No cercadinho (3 dias): com a **latinha Recovery** na mochila (a Fernanda deixa 3 na volta, já inclusas no valor, e diz isso na fala; à venda no Market, aba Pet), E no cercadinho alimenta um gato com fome por vez (uma latinha cada) (depois, o E pega o gato) (sem caixa de areia: fraldas descartáveis); o remédio do pós é o mesmo do remédio escondido. Sem comer, pode vir uma complicação pequena: leve à clínica e a Fernanda resolve, grátis. Quando a clínica abre e o Botinhas fica doente, a Fernanda aproveita a consulta para os testes e o checkup dele. Castrado fica mais calmo (confiança mais fácil, distrai mais no remédio). Adoção: só depois de castrado (e fora do cercadinho). Debug (F9), linha **Castração**: forçar o estado (real e o que ela sabe), idade e saúde; mandar para a consulta; castrar já; manhã da clínica; fim do cercadinho; lotar a agenda; complicação; e o estado real do gato escolhido.
- **CED: a vaquinha pelo CatPay** (`data/ced.json`, textos e cenas em `data/ced_text.json`, decisão 178; etapa A de 4): depois da primeira castração, de dia, a Fernanda liga, explica a CED e pede ajuda para arrecadar os materiais (ela faz a cirurgia por conta). Aí aparece o app **CatPay** no celular e a **plaquinha do CatPay** vai para a mochila: no balcão, os clientes doam bem mais quando pagam; moradores doam pelo app mesmo com ela longe do café (mais com o café bem avaliado e com corações). Uma doação por pessoa por dia; cada uma vira um aviso. No app: a meta (4 gatos x o kit de materiais), o saldo, o botão **Completar do caixa** (até 30% da meta), as doações e o extrato. Parada há dias, a Dona Neusa dá uma força. Meta batida: a Fernanda liga do fornecedor (a compra vai para o extrato) e depois ela liga para a Gabi; o app fica com "nenhuma vaquinha ativa". Debug (F9), linha **CED**: começar a vaquinha, doação no balcão, pelo app, ajuda do vizinho e completar a meta.
- **Luz e sombra de ambiente:** sem mudar a arte, cada objeto no chão e quem anda tem uma sombra macia embaixo, a parede escurece de leve onde encontra o piso, as janelas do café jogam luz quente no chão de dia (some à noite) e as bordas da tela têm uma vinheta leve. Toda lâmpada (os postes e o varal de luzinhas do quintal, abajures, lampião, luminárias, velas e a lanterna de Halloween) acende à noite, iluminando em volta, e a partir das 18h já fica acesa. O céu atrás do quintal muda com a estação (primavera florida, verão verde, outono laranja, inverno com neve) e, a partir das 18h, vira o céu da noite, com estrelas e janelas acesas (`data/seasons.json: tileVariants`). Números em `data/daynight.json: ambience`.
- **Falas do narrador** (sem personagem): quadro lavanda, texto em itálico e negrito; nas cenas, faixa lilás.
- **Dica E:** chegando perto de algo que dá para usar (balcão, prateleira, pedido, cliente, gato, sujeira com a vassoura na mão...), uma plaquinha "E" com a ação aparece em cima ("E Varrer", "E Ver a prateleira"...). É um tutorial: depois de 3 usos de cada tipo de coisa, a dica daquele tipo some.
- **Setas / WASD:** andar. **Segurar R:** correr (1,6x; carregando algo, corre um pouco menos: 1,3x por cima da velocidade de carregar; sem custo). Para entrar ou sair por uma porta, pare na frente dela e siga para cima.
- **C:** abre o celular direto no app **Market** (compra online, de qualquer lugar; chega em 1h na porta do café). **Caixas do correio:** E na porta pega as caixas; elas ficam nos braços (inclusive ao entrar). No café, E solta uma caixa na frente dela (salão, porão ou quintal), fechada; E perto de uma caixa no chão: **Abrir** (os itens vão para a mochila e os móveis saem para posicionar), **Carregar** (pega de volta) ou **Deixar**. Abas **Pet** (separada em Alimentação, Cuidados, Brinquedos, Descanso e Playground, com novelos coloridos, cesta de novelos, almofada capitonê e a caixa de areia verde; a prateleira pet do mercado também: Alimentação, Cuidados e Brinquedos, pelas tags `cat:food`, `cat:care`, `cat:toy` e `cat:rest` dos itens), **Móveis**, **Eletro** (eletrodomésticos e eletrônicos; o **espremedor** faz os sucos com a fruta fresca, sempre premium, e o liquidificador continua com a polpa), **Decor** (plantas altas, cactos, vasos, plantas penduradas, quadros, lousas, tapetes, capacho, geladeira de bebidas e, para o balcão, expositores de doces e pote de biscoitos) e **Construção** (**Obras** dos cômodos e as **obras do Tião**: reparo interno e da fachada, depois trocar o acabamento de uma ou mais áreas marcadas no café (arrastar marca; **Ctrl + arrastar** marca mais uma, e tudo vira uma obra só; Enter sem área marcada não confirma), uma obra por vez; ele liga com o orçamento, recebe adiantado e vem no dia seguinte; trabalhando, E perto dele (ou clique nele) e ele diz quantos dias faltam para terminar; no fim do expediente (ou depois de perguntar se você quer mais algum serviço), ele vai embora andando até a porta da rua, desviando dos móveis. Se, quando ele vier perguntar, você já tiver combinado a próxima obra por telefone, ele não pergunta: avisa que terminou e quando começa a nova. Da segunda ligação em diante, a conversa no telefone é curta (sem a apresentação); na troca de acabamento, por dia só 30% da área fica isolada com fita, numa faixa que anda da esquerda para a direita a cada dia da obra), cada item num cartão com a imagem. **Para que serve:** com o mouse parado 1,5 segundo em cima de um item (no Market ou nas prateleiras do mercado), aparece um balão com a dica (todo item tem `description` em `data/items.json`). Como no mercado, clicar põe o item no **pedido** (de novo, mais um; o − tira) e a barra embaixo mostra o total: só compra ao **Confirmar compra** (sem dinheiro para tudo, não compra nada; Limpar esvazia). Item que já está na bolsa: clique para posicionar (só dentro do café).
- **Clique** (ou **setas** para levar o fantasma e **Enter**): posicionar · **botão direito ou Esc:** cancelar (o item fica na bolsa). O fantasma começa na frente dela; enquanto ela segura o fantasma, fica parada.
- **Botão direito num móvel:** mudar de lugar sem passar pela mochila (o armário da despensa e o balcão com pia também: eles mudam de lugar, mas não vão para a mochila nem estão à venda; a despensa e a pia funcionam onde estiverem). O que está em cima (a cafeteira no balcão, a louça e os pedidos) vai junto; o original fica esmaecido até soltar. **Clique:** soltar · **Q:** guardar na mochila (com o que está em cima) · **botão direito ou Esc:** cancelar (nada muda). **F** (teclado): pega o móvel da frente dela (ou encostado; olhando para cima, também os da parede). Com mais de um móvel perto (ou botão direito numa célula com o globo em cima do balcão), o escolhido fica dourado com uma seta: **F** passa para o próximo, **E/Enter/clique** escolhe, **Esc** cancela; **setas/WASD** levam o fantasma uma célula por toque; **F ou Enter** solta.
- **Assistência técnica (Market, aba Assistência):** troca um móvel por outro do mesmo tipo, no mesmo lugar (outra peça do balcão, a cadeira virada para outro lado, outra cor, a tigela pelo pote automático). **Escolher o móvel no café:** os que têm troca piscam; clique neles ou chegue perto e aperte **E, F ou Enter**. Paga a diferença entre as peças (se a nova for mais cara) + 5 moedas do serviço. Os grupos de troca ficam em `data/items.json` (`upgrades`).
- **Espaço / Enter / clique:** avançar as falas
- **Mercado:** **E** numa prateleira põe itens no carrinho (+/−); **E** no caixa (pelo lado de cima: a atendente fica do outro lado, de costas, e passa as compras quando ela chega) mostra o total e paga. Sair sem pagar não cobra nada (o carrinho fica até dormir).
- **Jacque** (vizinha gateira, 6 gatos: Sabrina e Cacau, pretinhas; Branquinho, branco, com alergia; a Jojo, frajola conversadeira; Amora, tigrada; Feijão, siamês safado): aparece pela primeira vez no dia da 1ª feira de adoção, no quintal, depois da feira toda montada (chega, vem até você e se apresenta: gateira, acabou de se mudar para a rua). Depois, em cerca de metade dos dias, entre 16:30 e 18:30, atravessa a rua com 1 ou 2 dos gatos atrás; passando perto de você, acena e solta um balãozinho ("Vem, Amora, não fica pra trás!"); **E** nela: ela para e conta a novidade do dia sobre os gatos (uma frase por dia; todas saem antes de repetir; de novo no mesmo dia, a mesma frase; a conversa do dia dá um pouco de coração).
- **Vizinhos passeando** (`data/npcs.json: walks`): nem todo dia, cada um no seu canto e horário: a **Dona Neusa** de manhã na rua (8:30–10:30, indo ao mercado), a **Gabi** com o **Joca** na praça no almoço (12:00–14:00) e a **Jacque** no fim da tarde na rua. Passando perto, acenam com um balãozinho; **E** conversa (uma frase por dia; um pouco de coração).
- **Movimento na praça e na rua** (`data/npcs.json: ambient`, `src/core/ambientPeople.ts`): das 9h às 21h, figurantes (os clientes). Na **praça**: gente sentada nos bancos, em pé na banca, nos carrinhos de hot dog e pipoca, no bebedouro e olhando o chafariz, grupinhos de 2 ou 3 conversando (com balõezinhos) e gente passeando; a cada 2h30 a turma troca (uns somem devagar, outros aparecem). Na **rua**: gente atravessando de uma ponta à outra (ou saindo do mercado), alguém sentado no banco, olhando as frutas ou lendo a lousa do café. Com chuva ou neve, vem menos gente. Tudo sorteado com semente por dia (o mesmo ao voltar ao mapa).
- **Ponto de ônibus** (`data/world.json: bus`): na rua, entre o beco e a praça. **E** no ponto: **Ir para casa** (encerra o dia a qualquer hora, o atalho antes das 17h da porta do café; com cliente no café, ela espera o último sair) ou **Ficar**. Os destinos vêm dos dados, para incluir outros lugares depois. Arte provisória (placa por código, `ph_bus_stop`).
- **Jardim (quintal):** na primeira vez, o quintal está cheio de galhos, toras, folhas secas e mato, com árvores espalhadas; ela se assusta e liga para o Tião (limpeza pesada). Com ele em obra, só o aviso; depois, pela pergunta dele no fim da obra ou pelo Market. As árvores dá para remover (Mover e Q / Mochila no celular). No mercado da vila, a **banca de plantas** vende muda de árvore (cresce em uns dias: jovem, depois árvore) e mudas de grama alta e baixa (sem colisão).

- **Fluidez:** avisos empilham no alto da tela (até 3; o mais antigo sai, e o mesmo aviso não repete); perguntas abrem uma de cada vez; o E segue a ordem caixa da entrega, gato bem na frente (com a ração ou a areia na mão, o pote ou a caixa de areia), e depois o resto; um E no pote ou na caixa de areia usa a ração ou a areia da mochila, sem escolher na barra; itens pequenos de um pedido vêm na mesma caixa (até 4 espaços: item de 1 tile ou que não é móvel ocupa 1; o limite de 3 é de caixas, não de itens) e abrir a caixa tira tudo; com móveis, ela escolhe posicionar agora (um depois do outro) ou guardar na mochila, e o I durante o posicionamento guarda o item e abre a mochila.
- **Clima:** todo dia tem um clima, mostrado numa plaquinha embaixo da energia (ícone e nome). Na rua (e no quintal do café, depois de reformado) cai **chuva** (com o céu um pouco mais escuro), **neve** no inverno, e no outono o **vento** leva folhas. O clima também decide algumas chegadas de gatos (as pegadas na neve).
- **Horário da vila:** o **mercado** abre todo dia, das 07:00 às 20:00, e a **clínica**, de segunda a sábado, das 09:00 às 18:00. Fora do horário a porta não deixa entrar e avisa quando abre ("Mercado · fechado agora. Abre amanhã às 07:00."); quem já está dentro termina as compras. O Market do celular fica sempre aberto. **Plaquinhas de horário:** E (ou clique) na plaquinha ao lado da porta do mercado, da clínica e do café abre um quadro no centro da tela, como um mural: o status de agora (aberto, fechado e quando abre, ou almoço), a semana dia por dia (hoje em destaque, dias fechados escritos) e, no café, o almoço (segue o app Horário). E, Esc ou clique fecham; o relógio para enquanto ele está aberto. O aviso da porta fechada some ao trocar de lugar. No mapa, é a interação `{ "hours": "<id da porta>" }`.
- **Louça** (`data/items.json`, tag dishes): o café começa com a louça que a Gabi traz; no Market (aba Móveis, Para os clientes) há **Xícaras (6)**, **Copos (6)** e **Pratos (6)**: ao abrir a caixa, entram direto na louça limpa (cada pacote soma), para atender mais gente antes de lavar.
- **Pracinha e beco** (`data/maps/praca.json` e `alley.json`, gerados por `scripts/map-rua-extra.ts`): na rua, depois da clínica, ficam as entradas do **beco** (o vão entre os prédios) e da **pracinha** (o portal de ferro): suba nelas para entrar (a pracinha também abre andando para a direita na ponta da rua). A **pracinha** tem caminho de pedregulhos e praça calçada com o chafariz grande no centro, bancos, canteiros e postes; à esquerda o coreto, o bebedouro e o parquinho (balanço e escorregador); à direita a banca de jornal e os carrinhos de hot dog e pipoca. As árvores ficam direto na grama, de 4 jeitos (grande, média, fina e jovem), e mudam de cor por código: na primavera rosa, amarela ou verde; no outono laranja, vermelha ou dourada; no inverno com neve (a fina é sempre verde). No inverno o chão da praça fica todo coberto de neve, como o quintal (o tile de neve do PixelLab, `parque_*`), e a neve cai por cima das coisas, por código: telhados do coreto e da banca, guarda-sóis, canteiros, vasos, bancos, postes, brinquedos, copas e a sebe (folha `pixellab_praca_neve`, overlay que some fora do inverno). O **beco** atrás das casas tem chão de paralelepípedos (por código, como o da entrada), muro de tijolos com o varal preso em ganchos na parede, caçamba com montes de sacos de lixo do lado e outro do outro lado do beco, o poste velho logo depois (aceso à noite) e um caixote fechado (caixote e sacos do PixelLab). No inverno o chão fica coberto de neve e a neve cai por cima do muro e das coisas. Por enquanto, lugares para andar. As entradas na rua mudam com a estação (copas rosa na primavera, laranja no outono, neve e guirlanda no inverno) e o portal tem a placa "PRAÇA" (letras por código).
- **Neve por cima das coisas no inverno** (regra geral; `data/seasons.json: snowCaps`, `src/core/snowCap.ts`): tudo o que fica ao ar livre (a rua, a praça, o beco e o quintal do café) e não tem a neve própria ganha um montinho de neve por cima, feito por código seguindo o contorno do desenho: móveis do quintal, árvores, vasos, e também o mato, os galhos, as toras e as folhas do quintal abandonado. A sebe do quintal vira a versão com neve, e no chão do quintal ficam poças de neve e montinhos redondos de tamanhos diferentes (sozinhos, em dupla ou trio), sorteados por célula. Fora do inverno, nada.
- **Clínica da Fernanda** (fim da rua, a partir do dia 6): no dia 6 o primeiro gato adoece; na porta da obra do fim da rua ela descobre que a clínica inaugurou naquele dia, entra e pergunta à Fernanda se pode trazer o gato. Com o gato doente no colo (ele vai deitado nos braços, em qualquer mapa) (E perto dele), entre e aperte **E** na mesa de exame para a consulta (diagnóstico, receita de 1 a 7 dias e o preço; a primeira pode ser fiado). Em casa, com o **remédio** ativo na barra, **E** perto do gato dá a dose do dia. Cuidado: a **Fungadinha da Neve** passa de gato para gato (as outras doenças não): doente há mais de 2 dias e solto com a turma, passa para os outros, mesmo com o remédio. Para isolar, solte o gato no cercadinho (perto dele, o E põe lá); longe do cercadinho, um aviso pergunta: "Colocar no cercadinho" (se algum tem vaga; sem vaga, "Deixar na caixinha"), isolado, ou "Soltar mesmo assim". Isolado, não passa (o remédio é dado lá mesmo) e, quando sara, volta sozinho para a turma. No balão em cima do gato, junto com o que ele precisa (remédio, banho, carinho), o sinal da clínica: tesoura (operado, em recuperação), termômetro (doente) e micróbio (doença que passa, já diagnosticada); com mais de um, o balão alarga e mostra todos lado a lado (na caixinha, o balão fica em cima dela). Com 2 ou mais gatos doentes sem tratamento, os clientes deixam de entrar. Nenhum gato amanhece doente num dia em que a clínica não atende (domingo): a doença fica para o próximo dia de clínica aberta.

O jogo abre na tela inicial (Home): toque/clique, depois Continuar, Novo jogo, Carregar/recuperar saves, Opções e Créditos. No **Novo jogo**, depois do slot, vem **Sua personagem**: nome, pronome (**Ela** ou **Ele**: as poucas falas que têm gênero seguem essa escolha; o resto é escrito sem gênero) e aparência (pele, olhos, cabelo, roupa, parte de baixo, calçado, óculos e acessório), com prévia que gira, "Aleatório" e "Exemplos". Isso só se escolhe no início do jogo. O ano tem quatro estações de 30 dias: o jogo começa no inverno, e a inauguração do café só pode acontecer a partir da primavera (o inverno é o mês para reformar o salão e a fachada). O café cresce por cômodos, como recompensa de quem já toca o café: depois da inauguração (na primavera) e com 40 clientes atendidos, a Dona Neusa conta do **porão** (obra no Market, aba **Construção**): a porta fica na parede da direita do salão e uma escadinha desce para ele. Limpando o porão, ela acha uma chave enferrujada e guarda. Um mês (30 dias) depois de abrir o porão, a corretora passa no café e comenta que a planta tinha um quintal; a Dona Neusa lembra que era na parede dos fundos (a de cima) do salão, e o Tião acha a porta embaixo do papel de parede: a chave abre o **quintal secreto**; a saída do quintal fica embaixo, no capacho. Cômodo reformado libera funções: no porão, dormir no café. Esc no jogo abre a pausa (Continuar, Opções, Salvar, **Reiniciar o dia**, Voltar ao menu; reiniciar volta à manhã do dia, depois de confirmar: o jogo guarda uma foto do começo de cada dia por slot); com ela aberta, o jogo congela (gatos, clientes, animações e relógio) e a música de fundo para, voltando de onde parou ao continuar. Ao carregar um save, móvel que estiver em cima de outro, fora do mapa ou dentro de uma parede (save de uma versão antiga, por exemplo) volta para a mochila com um aviso, em vez de o café deixar de abrir. Recarregar a página (F5) volta à Home; o Continuar de lá abre o jogo direto, sem a pausa. Só pelo atalho que pula a Home (`?jogar`) o F5 volta ao jogo salvo já pausado, sem música, onde ela estiver; um jogo novo começa direto, sem a pausa.

Atalhos para testar (pulam a Home): `http://localhost:5173/?novo` começa um jogo novo no slot 1; `?jogar` continua o save mais recente (ou começa um novo).

### Celular e tablet (toque)
No celular ou tablet (tela de toque sem mouse), aparecem sozinhos um direcional à esquerda (empurrando até a borda, corre), o botão **E** à direita e os atalhos (pausa, celular, Market, cardápio, mochila, mover móvel). Tocar nas coisas também interage, e tocar na fala avança. Os botões seguem o último controle usado: tocou, aparecem; usou teclado ou mouse, somem. **Mudar móvel de lugar no toque:** **Mover** pega o móvel perto; com mais de um, o escolhido fica dourado com uma seta e os botões mudam: **Próximo** passa para o outro, **OK** (ou tocar nele) escolhe. Com o móvel na mão, toque no lugar ou use o direcional (uma célula por passo) e **Soltar**; Mochila guarda, ❚❚ cancela. A dica do rodapé fala dos botões de toque. Nos mini games ficam só o direcional e o E. Para testar no PC: `?toque` na URL. Código em `src/game/touch.ts` (o mundo e os mini games leem a direção dali junto com o teclado). Para abrir de outro aparelho na mesma rede: `http://<IP do PC>:5173`. **Tela cheia:** no Android, o botão ⛶ acima do direcional (some quando já está em tela cheia; deita a tela quando o celular deixa). No iPhone o navegador não deixa: use Compartilhar > **Adicionar à Tela de Início**, que abre o jogo como app, sem a barra (`public/manifest.webmanifest`; no Android também funciona pelo menu do Chrome). O manifest não fixa `start_url`: o atalho guarda o endereço de quando foi criado, com os parâmetros (ex.: `?debug=1`; nunca `?novo`, que começaria um jogo novo toda vez). No iPhone, o app da tela de início tem o próprio armazenamento (saves separados dos do Safari). HUD: no começo do jogo ficam só a data, a hora, as moedas e a energia; a reputação e o clima aparecem quando o café começa a atender (`data/world.json`: `hud`). Chegando perto de uma sujeira escondida atrás do HUD ou do balão, eles ficam transparentes (e o toque passa para o jogo). **Sujeira primeiro:** com a vassoura na mão, o E limpa a sujeira para onde ela está olhando antes de qualquer outra coisa (armário, pia, gato do lado), e tocar/clicar em cima de uma sujeira limpa em vez de abrir o que está perto. Os controles de toque somem na tela inicial, na pausa e com uma janela aberta por cima do jogo (mercado da vila, cardápio, celular, mochila). Tela menor que o jogo (640 x 360): ele encolhe até caber (fora disso, só escalas inteiras). Celular em pé: aviso "Gire o celular para jogar" por cima do jogo.

## Onde mexer

### Mudar o mapa do café
Edite `data/maps/cafe_main.json` e rode `npm run check`.

- `legend`: letra -> nome do tile (`"M": "floor_wood_a"`).
- `layers.floor` e `layers.walls`: uma string por linha, 16 caracteres cada. `.` = vazio.
- `objects`: móveis e enfeites. `at` é `[coluna, linha]` do canto superior esquerdo. O tamanho vem do catálogo.
- `spawn.player`: célula onde a personagem começa.

O formato completo está em `docs/DATA_CONTRACTS.md`. Se algo estiver errado, o `check` diz o quê e onde
(nome inexistente, peça fora do mapa, objetos sobrepostos, móvel dentro da parede...).

### Mudar se um tile é sólido ou em que camada fica
Edite `data/tiles.meta.json`. Cada tile tem:
- `solid`: bloqueia a personagem. Peças altas bloqueiam só a última linha (a base), como em Stardew.
- `layer`: `floor` (plano, embaixo de tudo, como o tapete), `wall` (preso à parede) ou `object` (entra no y-sort).

`data/tiles.csv` é cópia do pacote e não deve ser editado. `data/tiles.json` é gerado (`npm run tiles`) e fica fora do Git.

### Mudar a história, as falas, os preços
- `data/story.json`: marcos da história e metas do diário (condição -> efeito).
- `data/dialogue.json`: falas.
- `data/recipes.json`, `data/service.json`, `data/carry.json`: receitas, atendimento e mãos (tecla M: quadro do cardápio; I: mochila).
- `data/delivery.json`: correio (compras do Market chegam em 1h na porta do café).
- `data/jobs.json` e `data/news.json`: pedidos da vila (bicos) e o jornal "Vila Hoje" do celular (tecla P).
- `data/daynight.json`: cores do dia e da noite por hora e estação (o mapa diz se é `indoor` e onde ficam as `lights`).
- `data/items.json`: móveis do catálogo, nomes e preços.
- `data/maps/street.json`: a rua (fachadas, objetos, neve, porta do café). `data/world.json`: onde o jogo começa.
- `data/tilesets.json`: folhas extras de tiles (rua, neve, sujeira), com camada e solidez de cada peça. A arte pode ser de 32 ou 64 px por tile: vale o `tileSize` do JSON de peças em `data/tilesets/` (decisão 052). Folha com `replaces: true` troca só a imagem de tiles que já existem (mesmo nome e tamanho): é assim que a arte nova do PixelLab entra no café (decisão 065).
- `data/finishes.json`: acabamentos (pisos, papéis de parede, lambri, cores da fachada) e as obras do construtor (`construction`: reparos, preço por tile, horas). As superfícies reformáveis ficam no mapa (`surfaces`).
- `data/tiles.worn.json`: tiles velhos gerados do pacote (estilo de desgaste, troca de cores, variações).
- `data/economy.json`: dinheiro inicial.
- `data/ui_text.json`: textos da interface.

O formato está em `docs/DATA_CONTRACTS.md`. Rode `npm run check`: ele acusa referências quebradas (fala, item ou marco que não existe).

### Ajustar a personagem
`data/player.json`: velocidade, quadros por segundo e tamanho da caixa dos pés.

**A personagem** é o manequim do PixelLab (arte em 64 px) com roupa e cabelo em camadas (decisões 077, 083 e 087). No Novo jogo, "Sua personagem" escolhe nome, pronome, pele (clara, morena, parda, negra), penteado (longo, chanel, coque, rabo de cavalo, cacheado, afro, curto, afro curto, social, topete ou sem cabelo), cor do cabelo e roupa (moletom, camiseta, camisa de gola, vestido, blazer, casaco de inverno). As roupas ficam nas cores do desenho; pele e cabelo mudam de cor por código. Todas as peças andam e fazem as poses (bandeja, colo, ação); bandeja, gato e vassoura são desenhados pelo jogo. As peças saem de `npm run mannequin`.

## Como o código está organizado

```
data/          conteúdo (mapas, tiles, itens, história, falas, personagem)
src/core/      regras puras, sem Phaser: mapa, movimento, sessão, história, posicionamento, save (testadas)
src/game/      Phaser: cenas, sprites, teclado; ui/ = interface em HTML por cima do canvas
src/platform/  armazenamento (hoje localStorage; no futuro, arquivos via Electron)
scripts/       gerador do catálogo e validador do conteúdo
tests/core/    testes unitários
tests/e2e/     teste de fumaça no navegador
docs/          história, arquitetura, contratos de dados, arte, roadmap, decisões
```

Três ideias principais:
1. **O `core` decide, o Phaser só desenha.** Por exemplo, quais células são sólidas e qual a profundidade de cada peça
   são calculadas em `src/core/map.ts` (`solidBoxes`: paredes inteiras, móveis só na metade de baixo da célula da base).
   A cena só cria as imagens e os corpos de colisão.
2. **Y-sort:** a profundidade de cada objeto é a coordenada Y da base dele, e a da personagem é a base dos pés.
   Quem está mais embaixo na tela é desenhado por cima.
3. **Tudo passa pela `GameSession`** (`src/core/session.ts`): comprar, posicionar, recolher. Ela avança a história
   e avisa o resto por eventos (`item.placed`, `dialogue.requested`...). A cena e a interface só escutam.

Em `npm run dev`, a cena fica acessível no console do navegador como `__biscuitPaws.cafe`
(por exemplo `__biscuitPaws.cafe.teleportPlayer(3, 3)` ou `__biscuitPaws.cafe.sessionState()`).
